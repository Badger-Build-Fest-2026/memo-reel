# Build 3D Interactive Websites with ThreeUI

This video showcases ThreeUI, a massive web library containing over 100 interactive 3D UI elements, animated backgrounds, text animations, and full landing pages that developers can copy and customize using AI coding agents.

## Concepts

- **ThreeUI** — An interactive library by Design+Code containing pre-built, copy-pasteable 3D web components, landing pages, button animations, and custom shaders.

## Evidence

- The showcased website contains over 100 interactive 3D components and UI elements. (at 7.5s)
- Users can copy code prompts directly from the platform to paste into coding agents for rapid customization. (at 16.5s)
