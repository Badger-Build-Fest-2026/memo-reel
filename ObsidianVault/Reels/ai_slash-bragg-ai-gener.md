# Slash Bragg: AI-Generated Launch Videos

A hands-on test and review of the 'Slash Bragg' Claude skill (latent-spaces/brag), which automatically generates a high-quality 22-second promotional launch video from a side project's repository. The video shows the setup process, costs (~$6 in Claude API tokens), and the impressive final video output.

## Concepts

- **Slash Bragg (latent-spaces/brag)** — An open-source Claude skill/plugin that analyzes a codebase and generates a complete, high-quality promotional launch video in seconds.

## Evidence

- Slash Bragg is introduced as a Claude skill that turns side projects into a 22-second launch video, showing the latent-spaces/brag repository. (at 0.0s)
- The skill can be added using the CLI command 'npx skills add https://github.com/latent-spaces/brag --skill brag'. (at 9.5s)
- The generated launch video showcases key features of a storage cleaning app, such as compressing large videos and freeing up space. (at 27.5s)
