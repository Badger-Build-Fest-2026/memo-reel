# How to Create an Interactive Cursor-Tracking Character for Your Website

A step-by-step tutorial on creating an interactive website character that follows the user's cursor using ChatGPT, Google Flow, and Framer's AI component builder.

## Concepts

- **Pinterest** — Used to find 3D character style inspiration and model references.
- **ChatGPT** — Used to extend and format the character images in a 16:9 canvas using AI image prompting.
- **Google Flow** — An experimental Google Labs AI tool used to generate video animations (like eyes/head turning) from a static reference image.
- **Framer AI Component Builder** — Framer's built-in AI assistant, used to write React/code components from simple prompts, enabling advanced features like mouse cursor coordinate tracking to scrub video timelines.

## Evidence

- Searching for character ideas and references on Pinterest. (at 5.0s)
- Pasting the character image and prompting ChatGPT to generate a 16/9 image. (at 6.5s)
- Opening Google Flow at labs.google/fx/tools/flow to turn the character image into a video. (at 8.0s)
- Generating character head turns based on prompts in Google Flow. (at 12.5s)
- Creating a cursor-tracking component in Framer using an AI prompt. (at 14.0s)
- Uploading the generated video to the Framer component to enable interactive movement. (at 17.0s)
