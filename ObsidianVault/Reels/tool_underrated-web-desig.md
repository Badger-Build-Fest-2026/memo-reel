# Underrated Web Design and Creative Tools

A roundup of four useful and interactive web design, background design, and visual effect tools for developers and creators, including originkit.dev, pryzm.design, codepen.io, and ditther.com.

## Concepts

- **originkit.dev** — A web design platform providing interactive, animated UI components like the 3D 'Black Hole' model shown on screen.
- **pryzm.design** — An interactive digital canvas and visual studio used to design complex, textured, custom gradient backgrounds.
- **codepen.io** — An online code editor and playground, highlighted in the video for running interactive browser-based particle simulations.
- **ditther.com** — A web-based graphics tool that processes images and videos to apply stylized real-time dither, pixel art, or halftone visual effects.
