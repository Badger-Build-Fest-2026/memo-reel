# Cool Web Dev Tools and Resources - Part 5

A curation of impressive and useful web design resources for developers, featuring smooth scroll libraries, interactive landing pages, 3D animated background generators, and design inspiration hubs.

## Concepts

- **Lenis** — An open-source, lightweight smooth scroll library designed to enhance user experience on web pages.
- **basement.studio** — An award-winning digital studio showcasing next-level, immersive 3D interactive interfaces.
- **ShaderGradient** — An intuitive platform to generate, customize, and export fluid, moving 3D gradients for various design environments.
- **Unicorn Studio** — A curated collection of highly creative and interactive web designs to inspire front-end developers.
